### 01-2 원문 요지

1. **영→독** — big은 앙상블 포함 기존 최고보다 **2.0 이상** 높은 BLEU **28.4**. P100 8장으로 3.5일. **base조차** 기존 모든 모델·앙상블보다 높고, 학습 비용은 그 일부다.
2. **영→프** — big은 BLEU **41.0**(본문)으로 기존 모든 단일 모델보다 높고, 학습 비용은 기존 최고 모델의 **1/4 미만**. 이 모델은 Dropout을 0.3이 아니라 **0.1**로 썼다.
3. **체크포인트 평균** — base는 10분 간격으로 저장한 마지막 **5개**, big은 마지막 **20개**를 평균했다.
4. **빔 서치** — 빔 크기 **4**, 길이 벌점 **α = 0.6**. 개발 세트로 정했다. 최대 출력 길이는 **입력 길이 + 50**, 가능하면 일찍 끝낸다.
5. **학습 FLOPs 추정** — 학습 시간 × GPU 수 × GPU 한 장의 지속 단정밀도 성능. 각주 5: K80 2.8, K40 3.7, M40 6.0, **P100 9.5** TFLOPS.

**코드 1** · `code/ex09_flops.py` · Python 3 · NumPy · 검증: 실행함

```python
# 6.1절·각주 5: 학습 FLOPs ≈ 학습 시간 × GPU 수 × GPU 1개의 지속 성능(P100 = 9.5 TFLOPS)
p100 = 9.5e12
gpus = 8
base_sec = 12 * 3600          # 5.2절: base 12시간
big_sec = 3.5 * 24 * 3600     # 5.2절: big 3.5일

print(f"base: {base_sec * gpus * p100:.2e} FLOPs  (표 2: 3.3e18)")
print(f"big : {big_sec * gpus * p100:.2e} FLOPs  (표 2: 2.3e19)")
```

**실행 결과 1** · 위 코드를 실제로 실행한 출력

```text
base: 3.28e+18 FLOPs  (표 2: 3.3e18)
big : 2.30e+19 FLOPs  (표 2: 2.3e19)
```

#### 01-3 결과 쉽게 읽기

1. **base** — 12시간 × 8장 × 9.5 TFLOPS ≈ 3.28 × 10¹⁸. 표 2의 3.3 × 10¹⁸과 맞습니다.
2. **big** — 3.5일 × 8장 × 9.5 TFLOPS ≈ 2.30 × 10¹⁹. 표 2의 2.3 × 10¹⁹와 맞습니다.
3. 즉 표 2의 Transformer 비용은 **실제 측정이 아니라 이 식으로 추정**한 값입니다.

### 01-4 숫자를 읽을 때 조심할 점

1. **영→프 41.8 vs 41.0** — 표 2와 초록은 41.8, 6.1절 본문은 41.0입니다. v7 원문 그대로입니다.
2. **영→프 base 38.1** — base는 영→프에서 기존 모델보다 낮습니다. "base가 모두를 이겼다"는 **영→독에 대한 말**입니다.
3. **"1/4 미만 비용"** — 영→프 big의 FLOPs 칸은 표 2에서 비어 있습니다. 영→독과 같은 시간·장비로 학습했다면 2.3 × 10¹⁹로, 기존 최고 단일 모델(MoE 1.2 × 10²⁰, Deep-Att 1.0 × 10²⁰)의 1/4 미만입니다.

## 6.3절 · 영어 구문 분석

### 03-1 원문 요지

1. 다른 과제에도 일반화되는지 보려고 **영어 구문 분석**을 시험했다. 출력이 강한 구조 제약을 받고 입력보다 훨씬 길며, RNN 시퀀스 모델은 데이터가 적을 때 최고 성능을 내지 못했던 과제다.
2. **4층**, d_model = **1024** Transformer를 Penn Treebank의 **WSJ**(약 4만 문장)로 학습했다. 약 1700만 문장의 추가 말뭉치를 쓰는 **준지도 학습**도 했다.
3. 어휘는 WSJ만 쓸 때 **16K**, 준지도일 때 **32K**.
4. Dropout(어텐션·잔차), 학습률, 빔 크기만 개발 세트(Section 22)로 조금 골랐고, 나머지는 영→독 base와 같다.
5. 추론 때 최대 출력 길이를 **입력 길이 + 300**, 빔 크기 **21**, **α = 0.3**으로 했다.
