## 3절 도입 · 인코더와 디코더

#### 01-1 이 절에서 할 일

1. **할 일:** 인코더와 디코더가 각각 무엇을 받아 무엇을 내는지 봅니다.
2. **확인할 것:** 인코더는 한꺼번에, 디코더는 한 단어씩.

### 01-2 원문 요지

1. 경쟁력 있는 변환 모델은 대부분 **인코더·디코더** 구조다.
2. 인코더는 기호 시퀀스 (x1, …, xn)을 연속값 표현 **z = (z1, …, zn)**으로 바꾼다.
3. 디코더는 z를 받아 출력 시퀀스 (y1, …, ym)을 **한 번에 하나씩** 만든다.
4. 각 단계는 **자기회귀**다. 앞서 만든 기호를 다음 기호를 만들 때 추가 입력으로 쓴다.
5. Transformer도 이 큰 구조를 따르되, 인코더·디코더 모두 **셀프 어텐션과 위치별 완전연결층**을 쌓아 만든다.

![영어 I love you가 인코더를 거쳐 z1~z3이 되고, 디코더가 Ich, liebe, dich를 차례로 만든다](figs/f04_encdec.svg)

**그림 2.** 인코더·디코더와 자기회귀 (예시 문장은 설명용)

1. **인코더** — 입력 문장 전체를 한꺼번에 읽어 위치마다 표현 z를 만듭니다.
2. **디코더** — z와 지금까지 만든 단어를 보고 다음 단어 하나를 만듭니다.
3. **빨간 되먹임** — 만든 단어를 다시 디코더 입력에 넣습니다. 이것이 자기회귀입니다.

## 3.1절 · 인코더

#### 03-1 이 절에서 할 일

1. **할 일:** 인코더 층 하나의 내부와 잔차 연결 식을 봅니다.
2. **확인할 것:** 왜 모든 출력이 512칸으로 같아야 하는가.

### 03-2 원문 요지

1. 인코더는 **같은 층 N = 6개**를 쌓는다.
2. 층마다 서브층이 **2개**다. 첫째는 **멀티헤드 셀프 어텐션**, 둘째는 **위치별 완전연결 피드포워드 신경망**이다.
3. 두 서브층 각각을 **잔차 연결**로 감싸고, 그 뒤에 **LayerNorm**을 둔다.
4. 즉 서브층 출력은 아래 식이다. Sublayer(x)는 그 서브층이 하는 계산이다.
5. 잔차 연결이 되도록 모든 서브층과 임베딩층의 출력 크기를 **d_model = 512**로 맞춘다.

```FORMULA
출력 = LayerNorm( x + Sublayer(x) )
```

![x가 Sublayer를 거친 값과 옆길로 온 x가 더해진 뒤 LayerNorm을 거친다](figs/f04_sublayer.svg)

**그림 4.** 서브층 하나의 모양 (원문 그림 1의 Add & Norm)

1. **옆길(보라)** — 입력 x를 계산 결과에 그대로 더합니다.
2. **더하기 조건** — x와 Sublayer(x)의 크기가 같아야 더할 수 있습니다. 그래서 모두 512칸입니다.
3. **순서** — 계산 → 더하기 → 정돈. 이 배치를 **Post-LN**이라 부릅니다. 뒤의 GPT-2 등은 정돈을 계산 **앞**에 두는 Pre-LN으로 바꿉니다.

> **쉽게 말하면** 잔차 연결은 "고친 부분만 덧붙이는 수정"입니다. 원본(x)을 잃지 않으므로 층을 깊게 쌓아도 학습이 잘 됩니다.

## 3.1절 · 디코더

#### 04-1 이 절에서 할 일

1. **할 일:** 디코더가 인코더와 다른 점 두 가지를 봅니다.
2. **확인할 것:** 위치 i의 답이 i보다 앞 출력만 보게 만드는 두 장치.

### 04-2 원문 요지

1. 디코더도 **같은 층 N = 6개**를 쌓는다.
2. 인코더 층의 서브층 2개에 더해, **인코더 출력에 대해 멀티헤드 어텐션**을 하는 **세 번째 서브층**을 넣는다.
3. 인코더처럼 서브층마다 잔차 연결 + LayerNorm을 둔다.
4. 디코더 셀프 어텐션은 **뒤 위치를 참고하지 못하게** 바꾼다(마스크).
5. 이 마스크와 **출력 임베딩을 한 칸 밀어 넣는 것**을 함께 써서, 위치 i의 예측이 **i보다 앞의 알려진 출력에만** 의존하게 한다.

| 비교 | 인코더 층 | 디코더 층 |
|---|---|---|
| 서브층 수 | 2개 | 3개 |
| 셀프 어텐션 | 모든 위치를 봄 | 자기와 앞만 봄 (마스크) |
| 인코더 출력 참고 | 없음 | 가운데 서브층에서 K·V로 참고 |
| 잔차 + LayerNorm | 서브층마다 | 서브층마다 |

![디코더 입력은 시작 기호부터 한 칸 밀려 있고, 각 위치는 다음 단어를 답으로 맞힌다](figs/f04_shift.svg)

**그림 5.** 한 칸 밀기(shifted right)

1. **디코더 입력** — 정답 번역을 오른쪽으로 한 칸 밀고 맨 앞에 시작 기호를 넣습니다.
2. **답** — 위치 1은 "Ich", 위치 2는 "liebe"를 맞힙니다. 각 위치의 입력은 자기 답의 **바로 앞 단어**입니다.
3. **마스크** — 위치 2가 위치 3, 4의 입력("liebe" 뒤)을 보면 답을 미리 보는 셈입니다. 그래서 가립니다(5장).
4. **학습 때** — 정답 번역 전체를 한 번에 넣고 모든 위치를 **동시에** 학습합니다. 밀기와 마스크 덕분에 가능합니다.

> **쉽게 말하면** 받아쓰기 시험에서 "지금까지 받아 쓴 글"만 보고 다음 글자를 쓰게 하는 규칙입니다. 한 칸 밀기는 시험지를 나눠 주는 방법, 마스크는 뒷장을 가리는 종이입니다.

### 04-3 이 장 정리

1. Transformer는 **인코더 6층 + 디코더 6층**입니다. 모든 출력은 **512칸**입니다.
2. 서브층마다 **LayerNorm(x + Sublayer(x))** 입니다.
3. 디코더는 서브층이 하나 더 있고(인코더-디코더 어텐션), 셀프 어텐션에 **마스크**가 있습니다.
4. **한 칸 밀기 + 마스크**로 위치 i는 i보다 앞 출력만 봅니다.

### 04-4 자주 하는 오해

1. **"6층이 Transformer의 고정값이다"** — 아닙니다. 이 논문의 base·big 설정입니다. 6.2절 표 3에서 2·4·8층도 시험합니다.
2. **"디코더는 학습 때도 한 단어씩 만든다"** — 아닙니다. 학습 때는 정답을 한 칸 밀어 넣고 모든 위치를 동시에 계산합니다. 한 단어씩 만드는 것은 **번역할 때(추론)** 입니다.
