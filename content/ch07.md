## 비교 기준 세 가지

### 01-1 원문 요지

1. 길이가 같은 시퀀스 (x1, …, xn)을 (z1, …, zn)으로 바꾸는 층(인코더·디코더의 은닉층)으로 셀프 어텐션·순환·합성곱을 비교한다. xi, zi는 d칸이다.
2. 기준 ① **층 하나의 전체 계산량**
3. 기준 ② **병렬화할 수 있는 계산량** — 필요한 **최소 순차 연산 수**로 잰다.
4. 기준 ③ **먼 의존 관계 사이의 경로 길이** — 신호가 앞뒤로 지나야 하는 경로가 짧을수록 먼 관계를 배우기 쉽다. 그래서 두 위치 사이 **최대 경로 길이**를 비교한다.

| 기준 | 묻는 것 | 좋은 쪽 |
|---|---|---|
| ① 계산량 | 층 하나에 곱셈·덧셈이 얼마나 드나 | 작을수록 |
| ② 순차 연산 | 기다려야 하는 단계가 몇 개인가 | 작을수록 (병렬화) |
| ③ 최대 경로 | 가장 먼 두 위치가 몇 단계 떨어져 있나 | 짧을수록 (학습) |

## 표 1 읽기

**표 1** (원문 표 1. 출처: Vaswani 외, 2017, 6쪽. 원문 허락 문구에 따라 수록)

| 층 종류 | 층당 계산량 | 순차 연산 | 최대 경로 길이 |
|---|---|---|---|
| 셀프 어텐션 | O(n² · d) | O(1) | O(1) |
| 순환 | O(n · d²) | O(n) | O(n) |
| 합성곱 | O(k · n · d²) | O(1) | O(log_k(n)) |
| 셀프 어텐션 (제한) | O(r · n · d) | O(1) | O(n/r) |

### 02-1 한 줄씩 읽기

1. **셀프 어텐션** — 모든 위치 쌍(n²)을 d칸으로 비교합니다. 기다림 없이 한 번에(O(1)), 어느 두 위치든 1단계(O(1))입니다.
2. **순환** — 위치마다(n) d×d 행렬 곱을 합니다. n번 차례로 해야 하고, 처음과 끝은 n단계 떨어집니다.
3. **합성곱** — 위치마다 창 k칸에 d×d를 곱합니다. 병렬은 되지만, 창을 넓혀 가며 쌓아야 끝까지 닿습니다. 원문 표의 log_k(n)은 **팽창 합성곱** 기준입니다.
4. **제한 셀프 어텐션** — 이웃 r칸만 봅니다. 계산은 줄지만 먼 위치까지 n/r단계가 걸립니다.

> **쉽게 말하면** 셀프 어텐션은 순차 연산·경로 길이 두 칸이 모두 O(1)인 유일한 층입니다. 대신 계산량에 n²이 들어갑니다.

## 셀프 어텐션 vs 순환층

#### 03-1 이 절에서 할 일

1. **할 일:** n²·d와 n·d²를 실제 숫자로 비교합니다.
2. **확인할 것:** 어느 길이부터 순서가 뒤집히는가.

### 03-2 원문 요지

1. 셀프 어텐션은 모든 위치를 **상수 개의 순차 연산**으로 잇고, 순환층은 **O(n)**개가 필요하다.
2. 계산량은 **n < d** 일 때 셀프 어텐션이 더 빠르다. 당시 번역 모델의 문장 표현(워드피스·BPE)은 대부분 이 경우다.
3. 아주 긴 시퀀스는 각 위치 주변 **r칸만** 보도록 제한할 수 있다. 그러면 최대 경로가 O(n/r)로 늘어난다. 앞으로 연구할 계획이다.

**코드 1** · `code/ex07_complexity.py` · Python 3 · NumPy · 검증: 실행함

```python
# 표 1: 층 하나의 계산량 비교. 셀프 어텐션 n²·d, 순환층 n·d².
d = 512
for n in (30, 100, 512, 2000):
    sa, rnn = n * n * d, n * d * d
    faster = "셀프 어텐션" if sa < rnn else ("같음" if sa == rnn else "순환층")
    print(f"n={n:5d}  n²·d={sa:>13,}  n·d²={rnn:>13,}  더 적은 쪽: {faster}")
```

**실행 결과 1** · 위 코드를 실제로 실행한 출력

```text

n=  100  n²·d=    5,120,000  n·d²=   26,214,400  더 적은 쪽: 셀프 어텐션
```

## 셀프 어텐션 vs 합성곱층

### 04-1 원문 요지

1. 창 너비 k < n인 합성곱층 하나는 모든 입력·출력 위치 쌍을 잇지 못한다.
2. 이으려면 연속 창은 **O(n/k)층**, 팽창 합성곱은 **O(log_k(n))층**을 쌓아야 하고, 그만큼 최대 경로가 길어진다.
3. 합성곱층은 보통 순환층보다 **k배 비싸다.**
4. 분리 합성곱은 계산량을 O(k·n·d + n·d²)로 크게 줄인다. 그래도 k = n이면 **셀프 어텐션층 + 위치별 FFN층**과 같은 계산량이다. 그것이 이 논문이 택한 조합이다.

| 비교 | 합성곱 | 셀프 어텐션 |
|---|---|---|
| 한 층이 보는 범위 | 창 k칸 | 전체 n칸 |
| 전체를 잇는 데 필요한 층 | O(n/k) 또는 O(log_k(n)) | 1 |
| 층 하나의 비용 | 순환층의 약 k배 | n < d 이면 순환층보다 적음 |

## 덤 · 해석하기 쉬운 모델

### 05-1 원문 요지

1. 셀프 어텐션은 덤으로 **더 해석하기 쉬운** 모델을 만들 수 있다.
2. 모델의 어텐션 분포를 살펴본 예를 **부록**에 실었다(10장).
3. 헤드들이 분명히 서로 다른 일을 배우고, 여럿은 문장의 **문법·의미 구조**와 관련된 행동을 보인다.

### 05-2 이 장 정리

1. 비교 기준은 **계산량 · 순차 연산 · 최대 경로 길이** 세 가지입니다.
2. 셀프 어텐션은 **순차 연산 O(1), 최대 경로 O(1)** 입니다. 대가는 계산량 O(n²·d)입니다.
3. **n < d** 이면 계산량도 순환층보다 적습니다. d = 512이면 n = 512에서 같아집니다.
4. 긴 입력에는 이웃 r칸만 보는 **제한 셀프 어텐션**을 앞으로의 과제로 남겼습니다.

### 05-3 자주 하는 오해

1. **"셀프 어텐션은 항상 더 빠르다"** — 아닙니다. 계산량은 **n < d** 일 때만 적습니다. 순차 연산이 적어서 병렬화가 잘 된다는 것과는 다른 이야기입니다.
2. **"O(1) 경로면 먼 관계를 반드시 배운다"** — 표 1은 **배우기 쉬운 조건**을 비교한 것입니다. 실제로 배웠는지는 6절 결과와 부록 그림으로 확인합니다.
