# Attention 원문 해설서 — 최종 통합 적대적 검증 v13

## 검증 기준
- 입력: 최초 원본 `Attention 원문 해설서.zip`(11개 항목), 누적 `Attention_원문_해설서_v12.zip`(31개 항목). 두 ZIP의 CRC 검사 통과.
- 공식 원문: https://arxiv.org/html/1706.03762v7 (2017 발표, v7 2023-08-02).
- 개별 장의 검증 기록은 이전 버전의 역사적 기록으로 보존. 최종 파일은 원문 해설서 v04, 쉬운 해설서 v02로 통일.

## 발견 및 수정
| 대상 | 발견 및 조치 |
|---|---|
| INDEX | 1·2·5장 쉬운 해설서 링크 누락, 3장 링크가 목차 밖에 배치되어 있었음. 10개 장 모두 한 카드에 원문/쉬운 해설서 쌍을 배치. |
| 장 탐색 | 쉬운 해설서에서 이전·다음 및 사이드바 이동이 원문 모드로 바뀌는 오류. 현재 읽기 모드를 유지하며 상단 모드 전환 링크 추가. |
| 코드 복사 | 2·3·4장 일부 Python 코드에 복사 버튼 없음. 공통 코드 블록으로 변경. 출력 블록과 실행 코드의 복사 구분. 클립보드 실패 시 코드 선택 및 Ctrl+C 안내. |
| 예제 파일 | 본문에 표기된 일부 code/ex*.py 파일 누락. 실제 코드 32개와 기존 이름 호환 파일 10개 제공, 모든 실행 예제에 파일 링크 추가. |
| 3장 ↔ 7장 | 커널 폭이 서로 다른 교육용 예제를 동일 조건으로 비교할 위험. 각각의 반경 및 조건을 명시. |
| 4장 ↔ 8장 | 잔차 그림의 Dropout 생략과 학습 시 적용 순서를 연결하여 설명. |
| 4장 ↔ 5장 | 교차 어텐션의 Q 입력을 현재 디코더 층의 마스크 셀프 어텐션 뒤 Add & Norm 출력으로 명시; 5장 비교표 수정. |
| 5장 | 식 (1)의 투영 후 Q/K/V와 멀티헤드 식의 투영 전 입력 표기 구별. |
| 1·9·10장 | 영→프 41.8(초록·표2) / 41.0(6.1절), 구문 분석 성능의 원문 불일치가 기존 개정본에 명시되어 있음 확인. |
| 6장 | FFN 파라미터, 모델별 차원, 임베딩 공유, 위치 인코딩 파장, 보고값과 추정값 구분 확인. |
| 7장 | 표 1 대표항과 실제 밀집 어텐션 MAC 추정, 순차 단계와 클록 수 구분 확인. |
| 8장 | Adam 설정, warmup, 학습 및 추론의 Dropout, 스무딩 방식 구분 확인. |
| 9장 | 표 2~4의 주요 수치 및 학습 비용/실제 에너지 구분 확인. |
| 10장 | 후속 연구와 원문 결론의 구분 확인. |

## 실행 및 렌더링 검증
- Python 3.13.5, NumPy 2.3.5: 본문 코드 43회 실행, 고유 코드 32개, 저장 출력 40개 일치 및 본문 설명 3개 수동 대조 일치.
- HTML 21개 × 2개 뷰포트 = 42회 Chromium 렌더링: 문서 전체 가로 넘침 0, 이미지 로딩 실패 0, 페이지 JavaScript 오류 0. 모든 페이지의 내부 링크/앵커 대상 존재 확인. 모바일 메뉴 열기와 Escape 닫기 확인.
- SVG 99개 XML 파싱, PNG 6개 이미지 검사. 원문 PNG는 v12와 바이트 동일.
- 원문/쉬운 해설서 10쌍의 h2 제목 및 순서 동일.
- 링크 클릭 이벤트를 가로채 실제 대상 경로를 확인(목차→쉬운 해설서→다음 장→모드 전환→마지막 장→목차). 코드 복사 실패 시 선택 동작 확인.

## 미검증 및 배포 제한
- 실행 환경의 브라우저 정책이 로컬 파일 및 테스트 URL 탐색을 차단함. HTML 직접 로딩을 이용했고, 실제 파일 간 페이지 전환과 OS 클립보드 쓰기는 검증하지 못함. 링크 클릭 대상과 파일 존재, 복사 실패 대체 동작은 검증함.
- 외부 글꼴·외부 리소스는 차단한 상태. 원문 외부 링크의 전체 연결 상태, 모든 브라우저 및 모든 색상 대비의 WCAG 준수, 모든 그림의 픽셀 단위 시각 검증은 완료하지 못함.
- 기존 장의 원문 그림 5 직접 확인 제한은 유지. 논문 전체 학습 재현, GPU 성능 측정, FPGA 실장 검증은 범위 밖.
- 본문 코드의 실험은 수치 예제이며 원 논문 성능 재현이 아님.
