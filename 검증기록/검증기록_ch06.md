# 제06장 적대적 검증 기록 — v03 / 쉬운 해설서 v01

## 기준 자료
- 최초 업로드 `Attention 원문 해설서.zip`, 직전 누적 `Attention_원문_해설서_v07.zip`: ZIP 무결성 검사 정상. 제06장 main 본문과 6개 내장 SVG가 동일함을 확인(전체 HTML은 이전 장 탐색 경로 변경으로 다름).
- Vaswani 외, Attention Is All You Need (2017), arXiv:1706.03762v7 (2023-08-02): https://arxiv.org/html/1706.03762v7 — §3.3 식 (2), §3.4, §3.5, §5.1, 표 3(E), Base/Big 행. 공식 HTML 판본 확인.

## 발견 및 수정
| 대상 | 문제 | 조치 |
|---|---|---|
| FFN | Base와 일반 구조의 차원 혼동, 비선형성·서브층 경계 설명 부족 | Base 512→2048→512, Big 1024→4096→1024; W/b 크기, 위치별 가중치 공유, ReLU 및 Add & Norm 구분 |
| 임베딩 | 출력에서 공유 행렬 방향 미표기, 역변환으로 오해 가능 | E(V×d), 입력 행 조회 및 √d 배율, 출력 H Eᵀ, 로짓/확률 구분; 그림 3 문구 수정 |
| 공유 어휘 | 약 37,000은 모든 실험의 정확한 어휘 크기가 아님 | 영어→독일어 실험 기준, ID 호환 조건, 공유 절약량을 가정으로 명시 |
| 위치 인코딩 | 그림 4의 128개 표시 차원과 본문 512개 불일치 | Base 앞 128차원임을 본문·설명에 표시 |
| 주파수 | 유한 인덱스의 최종 파장과 10000·2π를 동일시할 가능성 | 실제 마지막 쌍 510·511, 약 60611.48; 점근 기준 약 62831.85. 지도 문구 수정 |
| 위치 이동 | 선형 이동 성질과 길이 외삽 성능 보장 혼동 | (sin,cos) 순서 회전 행렬, 고정 오프셋 조건, 외삽은 가설임을 명시 |
| 표 3(E) | 거의 같다는 결과의 구체 수치 부족 | 개발 세트 BLEU 25.8/25.7 및 PPL 4.92 확인 |
| 파라미터 | 표 3 근사치를 정확한 재현으로 오해 가능 | 계산 가정·출력 편향 제외 명시, Base 63,082,496 / Big 214,245,376 vs 보고값 65M/213M; 차이 원인 확정하지 않음 |
| 그림 출처 | 교재 그림 1과 논문 그림 1 혼동 | 두 그림을 구분. 원본 SVG 제작 경로는 ZIP 미포함 표시 |

## 테스트 결과
- 5개 절 ID(s00–s04) 및 기존 SVG 6개 유지. 개정본/쉬운 해설서 SVG XML 파싱 모두 성공. 그림 2개 라벨 개선, 나머지 그림 유지.
- 기존 Python 예제 2개 재실행: 저장 출력과 완전 일치. 쉬운 해설서 추가 NumPy 예제 3개(FFN 위치 독립성, 임베딩 공유, PE 덧셈) 재실행 및 단언문 통과. 전체 5개 고유 예제, 개정본 2개 및 쉬운 해설서 5개 출력 일치 확인.
- Chromium HTML 직접 로딩: 개정본/쉬운 해설서/index 각각 1440px, 390px에서 문서 폭 일치, 내장 이미지 로딩 성공, 페이지 JS 오류 없음. 두 해설서 모바일 메뉴 열기 및 Escape 닫기 성공. 데스크톱/모바일 쉬운 해설서 상단 스크린샷 육안 확인.
- 생성된 내부 링크 대상 파일 및 페이지 내 앵커 존재 확인. 양방향 해설서 링크 속성 확인. 다른 장 HTML은 제06장 파일명 링크 변경 이외의 수정 없음.
- 제한: 로컬 HTTP 접근은 ERR_BLOCKED_BY_ADMINISTRATOR로 실패하여 HTML 직접 로딩으로 대체. 실제 링크 이동, 클립보드 복사, 외부 리소스, 모든 브라우저, 실제 논문 학습 및 FPGA/NPU 구현은 미검증. 그림 4 내장 래스터 색상값 전체를 수치적으로 역검증하지는 않음.
