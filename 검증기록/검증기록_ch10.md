# 제10장 적대적 검증 기록

## 근거 및 범위
- 원본 ZIP 11개 파일, 누적 v11 ZIP 29개 파일: 압축 CRC 검사 통과. 제10장 원본 및 누적본을 확인하고 기존 4개 절과 내장 이미지 4개를 유지.
- Vaswani 외, Attention Is All You Need (2017), arXiv:1706.03762v7 (2023-08-02), [§7](https://arxiv.org/html/1706.03762v7#S7), [PDF](https://arxiv.org/pdf/1706.03762v7), 13–15쪽. 그림 3·4 스크린샷 및 그림 5 캡션 확인. 그림 5 스크린샷은 arXiv 접근 차단으로 미확인.
- 후속 연구는 개정본 03-5 출처 표 참조. 원문과 후속 연구를 분리.

## 문제 및 개선
1. 최초성 주장 범위를 시퀀스 변환 및 저자 주장으로 제한하고 FFN·잔차·정규화·교차 어텐션 명시.
2. 번역 성능과 시간은 논문 비교 실험 범위로 제한. 영→프 41.8/41.0 원문 불일치 명시.
3. 그림 3 장거리 연결은 의존 경로이며 클록 수가 아님. 기존 그림 3 데이터 그대로 유지.
4. 그림 4 상단 헤드 5 전체, 하단 its 질의 헤드 5·6의 집중 위치 설명. 그림 5는 선택된 두 헤드의 문장 구조 관련 패턴으로 제한. 가중치와 인과적 중요도 구분.
5. BERT의 MLM·NSP, 패딩 마스크 가능성 명시. GPT-2 Pre-LN을 GPT 전체로 일반화하지 않음. T5·Whisper는 인코더/디코더 골격의 변형, ViT-B/16의 패치 크기는 모델 선택임을 설명.
6. 세 개의 기존 SVG는 유지하면서 해당 도식 문구 수정. 쉬운 해설서에 가중합 그림 및 예제 3개 추가.
7. 이전 장 본문은 v11과 바이트 비교하여 제10장 파일명 탐색 링크 변경 외 차이 없음. index에 제10장 쉬운 해설서 연결.

## 실제 검사
- HTML 두 개의 main section 각각 4개, img 각각 4/5개, 내장 SVG 각각 3/4개 XML 파싱 성공.
- 쉬운 해설서의 Python 3 코드 3개를 실제 실행하고 저장된 출력과 비교: 모두 일치.
- Chromium 1440/390px 각 2개 페이지: 가로 넘침 없음, 모든 img 로딩 성공, 동적 탐색 링크 15개 생성, 페이지 JS 오류 0. 모바일 메뉴 열기 및 Escape 닫기 성공. 390px 쉬운 해설서 첫 화면 캡처 확인.
- 전체 HTML의 정적 링크와 COURSE JSON file 대상 파일 존재 검사 통과. 상호 해설서 링크의 href 확인.
- 로컬 file:// 접근은 ERR_BLOCKED_BY_ADMINISTRATOR이므로 set_content로 대체, 외부 HTTP(S) 요청 차단. 실제 페이지 이동 및 복사 버튼, 외부 리소스, 다른 브라우저, 논문 학습 재현은 미검증.
- 원문 그림 4·5는 새로 내장하지 않고 원문 PDF 페이지 링크 제공. 기존 ZIP의 편집용 SVG 원본 경로는 포함되지 않았음을 본문 명시.
- 제10장 완료. 다음 단계: 전체 10장과 쉬운 해설서의 통합 적대적 검증(특히 장간 용어, 수식, 예제, 탐색, 출처 및 모바일).
