## 재검증
- 원본 5개 그림 및 4개 절 유지; SVG XML 파싱 통과.
- HTML 정적 링크의 대상 파일 존재 확인. 2~10장 본문이 원본과 동일함을 비교 확인(1장 파일명 변경에 따른 탐색 링크만 갱신).
- Chromium 1440×900, 390×844: 목차, 개정본, 쉬운 해설서 렌더링에서 그림 로드, 페이지 폭, 스크립트 예외 없음 확인. 외부 웹폰트 요청을 차단한 상태로 테스트했으며, 실제 사용자 브라우저의 네트워크 환경과 전체 상호작용은 미검증.
- 논문 실험 재현은 수행하지 않음. 원문 수치 불일치는 임의 정정하지 않음.

## 진행
- 1/10 완료(개정본 v03 / 쉬운 해설서 v01). 2~10장 내용 검증 미실시. 전체 최종 교차 검증은 10장 완료 후 수행.
