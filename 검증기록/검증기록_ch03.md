# 제03장 검증 기록
- 원본 ZIP 및 v04 누적 ZIP 접근 확인. 기존 4절 및 내장 SVG 3개 유지.
- 공식 원문 arXiv:1706.03762v7 §2, §3.2, §4 대조. 최초성 주장 범위, 교차 어텐션, 마스크, 경로와 연산량 구분, 멀티헤드의 역할 비보장 반영.
- 기존 ByteNet 그림 1→2→4→9는 간격 1,2,5로 두 배 확장 설명과 불일치. 간격 1,2,4,8의 교육 모형으로 수정. 거리 8은 4층, 거리 32는 6층. 앞 세 층 자기 위치 유지 경로는 그림에서 생략하고 본문 명시. 실제 ByteNet 구조 재현 아님.
- Python 예제 실제 실행: 4; 누적 반경 1,3,7,15; 가중합 5.0,2.6,7.4.
- 두 HTML의 내장 SVG 각 3개 XML 파싱 통과, 명시적 로컬 앵커 파일 존재 확인. Chromium 1440/390px 각각 문서 폭 일치, 이미지 로딩 성공, 페이지 오류 없음. file URL 정책 차단으로 set_content 사용, 외부 HTTPS 차단. 실제 파일 이동 클릭 및 모든 상호작용은 미검증.
- 다음: 제04장. 전체 통합 검증은 제10장 이후.
